# 从手上的材料开始

## 我要做一期小红书轮播

先写下封面问的问题，以及末页能给读者的回答。把中间各页按证据顺序排出来。比如要讲一场代言，可以先比较同日官宣的互动，再看官博下有哪些具体回应，接着才轮到同款的价格、规格和适用场景。每一页的标题写出那一页多告诉读者什么。

> 用 $visual-story-styles 的 collage。简报是……；目标读者是……；附有已核验的数据表、品牌图的来源和可用范围。请先用我的图排封面、最密的数据页和商品页，输出一张并排预览。我的主色是……。

核对整组的主色、字族和来源位置。喜欢哪一版就沿用它的读序。交付按页编号的成图、可编辑源文件与数据口径。[拼贴配方](../references/collage.md)

## 我要把这篇改成公众号

公众号头图要在很小的预览里读得出主判断。正文图可以让读者停下来比较两款产品或看一个局部。在正文里找到需要图片支持的那句话，再决定主视觉的比例。横幅和正文图分别导出。

> 把已确认的轮播适配到公众号。头图保留最重要的一句话；正文比较图保留原色、型号、同尺码价格和日期。请给出图片应插在哪一段，导出后看一遍标题右边和鞋尖下边。

替换配图时打开独立 PNG、HTML 预览和导入文档，核对三处显示的是同一次修订。案例中标题和鞋尖的裁切问题都发生在成图阶段。[修订实录](../examples/warrior-case.md)

## 我要用自己的数据替换示例

从 [简报](../examples/brief.json) 的三行数据开始，替换对象、值、单位和观察时长。缺失项留空，零值写 0；两项占比先各自说明分母。给图表和图下注明来源，最后用一项已知读数核算渲染结果。每次换长标题或加一个对象，重新检查图的边界。[数据说明模板](../examples/data-viz-contract.json)

## 我只想修一页

把原页和最满意的一页并排，给出实际阅读宽度。用一句话说出现在看不清的对象，例如“商品鞋边的黑线在圆形裁切外”。只改直接影响辨认的照片尺度、文字宽度或留白，再用同一尺寸对照。[编辑排版方法](../references/impeccable-collage-trial.md)

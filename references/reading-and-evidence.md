# 阅读、图型与证据

## 图型由读者任务决定

| 要回答的问题 | 候选图型 | 所需数据与提醒 |
|---|---|---|
| 谁更高，差多少 | 排序点图、条形图 | 同指标同口径，条形长度通常从零起 |
| 同对象前后变多少 | 配对点、哑铃 | 同单位和时间窗口；配对身份明确 |
| 多对象每月怎样变化 | 矩阵、热图、小多图 | 缺失单独编码，名次与数值分开 |
| 一个总量由谁组成 | 100%堆叠、条带 | 已知且可加的分母，复核合计 |
| 换指标后排序如何 | 排名连线 | 各列日期明确，跨指标连线不暗示时间变化 |
| 两项指标有什么关系 | 散点 | 坐标单位、直接标签；小样本无需硬拟合 |
| 哪些事件先后发生 | 日期轴、事件卡 | 身份与事件类型明确，先后关系不自动成为因果 |
| 资源/用户如何流动 | 有真实流量的流带；建议流程用等宽连线 | 流带宽度需要可追溯流量，未知转化不画数值比例 |

## 作者编辑自检

1. 标题能否回答一句完整问题；每页比上一页增加了什么？
2. 对象、指标、单位、分母与时间在读者判断之前是否可见？
3. 关键值是否可以直接找到；是否依赖颜色或跨页图例才能识别？
4. 装饰、纹理、头像是否影响测量与读序；字体是否在手机尺寸可读？
5. 事实、计算、推断与行动建议是否表达清楚？
6. 数值由输入复算，缺失保留缺失，图表类型与字段一致。

检查结果逐项写“通过/待修/未检查”及实际位置。AI模拟读者属于编辑走查，不能作为真人研究数据。

## 可选真实试读与复用

用具体任务观察读者：复述主结论；指出比较对象和窗口；找指定数字；用自己的素材替换一页。记录实际成功/错误、用时和卡点。对照两版时尽量控制材料和任务，交替展示顺序；说明样本和探索性范围。

预期可读与实测理解分别报告。任务完成率需要真实人数与判定标准；用时改善需要同条件实测。下载、收藏、称赞和付费各反映不同动作。

## 分享与迭代记录

每次实际使用保留：输入版本、风格、运行环境、生成物、数字核验、预览范围、失败与修订。数据图和实际主体素材的来源跟随文件。公开包移除个人标识、私有资料与未获分享权限的照片。

增加新风格时，先证明它解决的阅读或制作问题与现有配方有实质差异，再用不同题材检查。成功生成一张图与完成整套可复用工作流分开记录。

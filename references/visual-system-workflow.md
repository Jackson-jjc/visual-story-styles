# 从参考作品到可复用的视觉系统

适用：用户给参考图、希望把新风格整理成 Skill，或整套图文存在风格漂移。沿用当前账号定位和用户选定方向。

## 方法来源与采用范围

2026-11-07阅读 EARS / Jane（小耳）的[《把顶级大牌的设计基因，拆到你的产品图workflow里》](https://mp.weixin.qq.com/s/Aa69TXXsOnzCreW7tH5b5w)，完整正文及10幅配图均可取得。其介绍 Amir Mušić 的 image-to-engine 方法：解析参考、迁移品牌、预览系列、明确简报、形成主视觉，再复用流程。本文把这个思路改编为有证据的知识图文生产；下列提示与验收为本 Skill 的应用设计。

原文中的平台流量、批量产量和模型称谓按作者叙述处理，不用作效果承诺。X原文链接检索可定位，正文访问返回403；LTX项目未运行。示例为概念广告，品牌名称不构成真实合作证明。

## 1. 把审美描述写成可观察的规则

检查参考图与当前成品，记录“观察—用途—迁移取舍”。颜色可从图中采样；估计尺寸明确为估计。使用一张主参考与少量补充参考即可。

| 观察对象 | 要写清什么 | 知识图文的迁移决定 |
|---|---|---|
| 第一眼焦点 | 哪个对象最大、对比最强 | 封面让读者识别主题；内页让主结论与证据优先 |
| 色彩角色 | 背景、文字、强调、类别分别用什么 | 将成员色与界面色分开，保证跨页一致 |
| 材质与层次 | 纸张、织物、金属、阴影在哪些区域出现 | 纹理留给边缘和照片承托区，坐标与标签用平整底色 |
| 字体与节奏 | 字重、字幅、字距、行距及长短句关系 | 中文按实有字库重排；英文视觉不能直接套到长中文标题 |
| 构图与网格 | 对齐线、主次比例、间距、留白方向 | 记录可编辑边距与列宽，长标签有明确容纳区域 |
| 识别元素 | 重复出现的物件或装置 | 给它固定功能，如档案标签承担指标与日期索引 |
| 图像策略 | 近景/全景、裁切、重复节奏 | 人物保持可辨认，照片日期和来源随素材保存 |

“时尚”“高级”可作方向描述，交付时需要转成以上可观察条件。保留原有对象身份和真实数据。

## 2. 写一份短简报，保存共享参数

简报回答：谁看、看完能做什么、本页证据支持什么、主要设计想法、用户可带走什么、如何检查。概念可来自两个有意义的视觉特征组合，例如“档案检索的秩序＋音乐作品的个性”。内容适合平实表达时直接使用清晰的信息层级。

用独立配置保存背景/文本/强调/类别颜色、字体角色、画布尺寸、安全边距、照片区域和来源区。另存逐页文案、数据、来源、照片；避免将统计数据埋入生成式图片提示中。示例字段见 [system-contract.json](../examples/system-contract.json)。

## 3. 先让代表页证明整套方向可用

整套制作可先组合封面、信息最密页、方法/收尾页的低成本草图，覆盖吸引、理解、复用三个任务。确定方向后扩展完整图组；用户已授权制作时，由作者检查并继续。

风格板展示色样、实际中文标题、数字与图例、照片边框、一个真实图表模块；拼成模块网格方便比较。这个网格是内部提案的工具，发布页仍由阅读任务决定。精简重复模块时保留证据，不固定要求删去某个百分比。

## 4. 用局部修订保持已经正确的部分

修订指令写清位置、现象、目标和保留项。例如：“第5页下方成员标签挤在数值上方；扩大标签行空间，保持数据和条带比例；重新检查360px预览。”

真正改图像时使用当前环境图像编辑工具；文字、统计图、来源标记由确定性排版生成。改共享色板或字体后检查所有受影响页面；改一处文案时先检查该页及总览。关键数值由原始数据重算。

## 5. 可直接使用的自编提示

**提炼参考**：
“结合参考图与本次读者任务，列出焦点、色彩角色、材质位置、字体层级、网格、识别物件和照片裁切。每项附观察依据、迁移决定和可编辑参数。把用户已确认的风格保留在方案中。”

**迁移成图组**：
“使用已保存的视觉参数与当前内容，先制作封面、最密数据页和复用页的草图总览。标出结论、图表、照片、来源的区域；保证中文长标题和数据标签有足够空间。确认读序后继续整套制作。”

**局部修订**：
“修正[页码/区域]的[可见问题]，目标为[可检查的结果]。保持[正确的事实、颜色含义、照片身份]，重渲染受影响页面并报告实际检查范围。”

## 6. 交付与验证

交付用户所需成图，同时提供参数、可编辑文件和替换说明。可分享包只放有权再分发的内容。研究摘记与第三方原图留在学习材料中，Skill保留出处与自主改编规则。

作者走查：在180px封面找到主题；在360px数据页找到对象、数值、日期和分母；检查装饰与照片不遮关键内容。将结果标为作者检查。真实试读另记人数、任务与观察。

复用测试选一次实质变化，如长标题、不同类别数量或新题材；运行后记录结果。只写了规则或配置时，状态是“规则已整理”，完整渲染后才记录制作验证。工具调用量与节省量以实测日志为依据。

## 补充学习与跨平台使用（2026-11-07）

本参考统一维护跨平台的制作方法。案例来源与自主改编范围见 [SOURCES.md](../SOURCES.md)；学习归档和第三方全文不随公开仓库分发。

简报可以在草图前写初稿，代表页检查后更新定稿。主问题、主对象和证据不随换风格而改变；保存字体/色彩等共享参数与逐图数据的独立输入。原文4:3品牌板、bento总览、减少30%图片是示例手段，按任务取舍。

**简报定稿指令**：将已确定的读者、核心问题、证据范围、作者判断、视觉主对象、参数和各图职责收束到一页，列出需要实际检查的条件。方法分享与商业入口由平台内容简报决定。

**主视觉指令**：用一个可辨认的主对象和清楚构图兑现标题，为中文标题留独立安全区。真实人物、包装和商品证据沿用源图，不能生成被遮挡细节来补证据；装饰、标题与数据使用可分开修订的层。

整套总览可含封面、数据图、实物拼贴、引语卡或收尾页，按内容职责选择。公众号文化文章的收尾可以是作者判断和讨论入口，无须加入方法教程；小红书方法笔记的复用动作由其内容 Skill 提供。

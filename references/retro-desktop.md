# 复古桌面档案：让窗口承担信息组织

## 参数起点

桌面浅青 `#C1E4EB`，档案纸 `#FFFBEE`，墨色 `#15264B`，标题栏钴蓝 `#1235BD`，次级文字 `#58647B`，文件夹淡黄 `#F9E8A7`。

默认画布1080×1440；外边距约48–72px；主标题约58–76px，正文42–48px，短图注32–36px。细边框与少量硬阴影形成窗口层次。正文使用现代清晰字体，等宽或像素字体仅作短文件名和编号。

颜色和字级统一，窗口数量按内容需要变化。每页主要证据拥有连续空间，避免每个段落被套进一个窗口。

## 语义对应

| 桌面元素 | 应承担的信息 | 避免的误导 |
|---|---|---|
| 文件名/窗口标题 | 指标、年份或阅读任务，如“六人·同月排名” | 用乱码、随机文件名占据关键位置 |
| 文件夹/标签页 | 章节或证据分类 | 画出含糊的可点击按钮让静态图像像故障界面 |
| 照片预览窗 | 对象身份、图像日期与来源 | 用旧图冒充当前活动截图 |
| 状态栏 | 页码、版本或数据截止日 | 虚构系统完成状态或进度 |
| 光标/选中框 | 指向需要关注的位置 | 遮挡数字或把选择状态当排名 |

这是编辑设计的桌面隐喻，真实软件截图另行注明来源。关键状态和数值只写已观察内容。

## 页面配方

- **封面**：主标题与一张主照片组成首要阅读区域，另一小窗口交代成品或原始材料。保留桌面边缘，档案编号从属正文。
- **数据比较**：一个主要证据窗口，标题栏写比较任务；内部用哑铃、点图或矩阵。照片小幅出现，源数据与时间靠近对应数字。
- **步骤/改稿**：旧版与新版采用同一比例，标出一至三处改变；无实测时只写编辑目的，效果留给试读。
- **履历/档案**：时间轴或分类表，文件夹只作索引；日期间距若为示意，应明确说明。
- **结尾**：一个结果窗口回答主问题，旁边按平台内容简报提供讨论入口或复用动作；准确标记本地文件或公开链接。

## 图表融入方式

在统一浅纸背景上绘制，使用相同字级、线宽和强调色；坐标与标注保持水平。圆盘、文件夹和窗口面积不参与统计编码，除非图例明确且真实值驱动。图型数量由实际问题决定。

## 常见修订

- 太像办公截图：加强主标题、照片尺度和窗口层级，减少工具栏装饰。
- 太像游戏菜单：减少按钮与图标，放大结论和证据。
- 密集窗口让读者逐个寻找信息：合并相关内容，将一个问题放到同一证据区域。
- 每页同一张照片：按页面作用选择不同来源照片，保持时间和许可记录；无需为凑数量加入无关图。
- 配色干扰成员比较：成员颜色跨页稳定，钴蓝保留为界面或选定重点，避免同色含义冲突。

# 数据可视化 harness：证据、布局、检查与复用

用于文本/评论分析、文化研究图文、仪表盘改为轮播，以及从参考作品中沉淀可复用版式。先读已有数据与用户要求，按实际任务使用以下检查；纯装饰修改无需重新采集数据。

## 方法来源与覆盖范围

本流程由设计系统文章和课程可视化案例的阅读观察，以及作者知识图文实践整理而来；归因见 [SOURCES.md](../SOURCES.md)。本仓库仅分发自主整理的规则与示例输入，不分发第三方作品原图、全文或私人学习档案。参考作品的原始数据与在线交互未全部复算或操作，不能把观察结论当作其统计结果已获验证。

## A. 数据进入图表之前

每个项目保存一份数据说明，字段可参考 [数据说明示例](../examples/data-viz-contract.json)：

- 研究问题、对象、来源链接/文件与采集日期。
- 纳入/排除规则、时间窗、原始条数、去重后条数、缺失与筛选原因。
- 指标定义、单位、分母、哪些对象能够直接比较。
- 数据原文件、清洗规则、统计输出与成图各自路径。
- 证据状态：来源报告、已复算、未核验，分别写清。

评论文本分析增加：去重键；停用词版本；专名/同义词词典；分词方式；按出现总次数还是按含词评论数计数；表情和否定词处理。讨论情感时记录语境核查或分类方法与抽样复核。词频回答出现频繁的内容，态度、购买意愿和因果需要对应证据。

工具按职能选择：采集→清洗→统计→排版→导出。课程提及的八爪鱼、火车头、Excel、SPSS、Rost、CiteSpace、微词云、RAWGraphs、FineBI、Flourish、Workbuddy作为历史案例工具清单；当前功能、费用与可访问性使用时另查。不要把文献共现分析、评论分词和情感分析视为同一任务。

## B. 从问题选择编码

| 阅读任务 | 优先结构 | 必备条件 |
|---|---|---|
| 认出讨论主题 | 关键词卡/词云＋少量解释 | 说明筛选与计数口径，频率可以追溯 |
| 精确比较两组词频 | 对齐点图/条形/直接数表 | 共同词表，同一单位；跨样本量时给归一化分母 |
| 检查某词集中在哪个对象 | 词×对象矩阵 | 缺失与零区分，统一图例 |
| 展示分析过程 | 阶段流程与输入/输出样例 | 连线表示流程，粗细无统计含义时等宽 |
| 展示作品风格体系 | 主样张＋参数样片＋应用小样 | 色彩角色、真实字级与版面规则可查 |

词云面积、字体视觉面积和字数之间存在差异。精确排名附对齐的数值表达。两幅词云独立自动缩放或独立分箱时，读者只能在各自内部识别突出词；要跨图比较，使用统一映射或改成直接比较图。

进一步检查：
- **词次与人数**：同一条评论可能重复一个词。保留总词次与含词评论数两个字段；来源样本按热度抽取时，描述对象为该样本。
- **来源字段与主题**：字段出现“监测点/分值”时，先确认测量对象、单位与数据提供者，标题使用可确认名称。分数、记录数、人数与项目数分别标单位。
- **名录口径**：累计公布、当前名录、母项目、地区子项、存续人数分别保存。跨图有总量差异时先解释口径，再比较。
- **统计层级**：省级样本与门类样本分别标n；GDP总量与人均GDP分别编码，相关系数随数据/变量/窗口变更重新计算。
- **桑基图**：同一批记录的“地区—类别—批次”是多属性归属；节点分层不表示人员迁移或因果。每层合计与总样本相符，分拆记录保留权重，阶段间不重复计总量。
- **地图**：记录坐标来源、空间粒度、权重、聚合与平滑参数。城市中心定位表示城市汇总，颜色浓度需说明数值；分级设色图的缺失单独编码。
- **标题/图例绑定**：用稳定的对象ID关联表、图、说明和来源；检查视频1/2、地区、图型名、单位是否错配。先确认再写研究结论。

## C. 可调用的版式配方

1. **证据表＋主题区**：顶部结论与样本；左侧紧凑查数表；右侧主题视图；底部解释与来源。宽屏适合并列，竖屏拆成“主发现、比较、完整数据”多页。
2. **主样张＋视觉参数**：一个大样张建立方向，侧栏放色板、材质、字级；下方少量应用。适合制作内部风格板，发布时只保留与阅读任务相关的模块。
3. **概念＋对象＋行动**：左侧一句问题及读者任务，右侧主对象，下方具体行动或方法。三个区域有明确主次，移动端按阅读顺序上下排列。
4. **输入—操作—结果**：每个阶段用一张代表图/表，箭头连到对应输出。多结果时用短分支或编号，给连线独立空隙。
5. **人物＋留白标题**：主体保留身份和关键细节，标题落在低纹理区域；手机裁切后仍能识别人和主问题。数据页面换用证据主导的结构。
6. **同构小多图**：保持坐标轴、图例与注释位置一致，图间只替换比较变量；分别写清变量单位和样本。图后用同编号结论对应。
7. **空间主图＋关系侧栏**：大地图回答“在哪里”，侧栏散点回答“与什么同变”；下方用数据定义和重点地区承接。手机上拆为两页，保留共同标题与对象。
8. **累计与新增双层图**：上层阶梯/折线表示累计，下层柱表示各批新增，时间轴对齐；短表核对两种口径。不同日期间隔按真实时间或明确的批次分类轴表示。

以上为从观察提炼的通用配方，比例与字体按本次画布重新确定；现有复古桌面和拼贴色彩规则继续沿用。

## D. 每次运行留下可检查记录

| 检查 | 记录 |
|---|---|
| 来源与完整性 | 哪些页面/图已读，空白、截断或未载入在哪里 |
| 数据与计算 | 输入版本、样本量、分母、缺失、复算结果 |
| 比较尺度 | 共享尺度或各图独立；如何在图上说明 |
| 页面理解 | 结论、对象、数值、日期、来源是否能定位 |
| 手机阅读 | 实际360–390px渲染，180px封面；问题与修订位置 |
| 复用 | 改长标题/类别数/主题后的实际输出；未运行写待验证 |

截图中的滑块与按钮只证明界面存在，交互是否可用需实际操作。缺图常见于网页打印的懒加载内容；检查PDF图像对象与页面渲染，再索取原文或完整导出。空白页不作为有效留白设计范例。

## E. 回填规则

发现失败时写成“输入场景—观察到的问题—局部修改—实际复查结果”，再决定是否成为通用规则。保留原始输入和作品来源；将业务结论、设计推断、作者检查与真人试读分开。模板可复用性与付费需求分别验证。
